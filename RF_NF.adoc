== 1. Visão Geral
Este documento especifica os requisitos funcionais essenciais (Mínimo Viável - MVP) do sistema.

== 2. Requisitos Essenciais

[cols="1,2,4,1", options="header"]
|===
| ID | Título | Descrição | Prioridade

| RF005
| Envio de Atestado Médico
| O sistema deverá permitir que o aluno envie um atestado médico para análise da escola.
| Atores: Alunos
| Prioridade: Essencial 
| Entradas e Pre-condições: O aluno deverá estar autenticado no sistema e selecionar um arquivo de atestado médico válido para realizar o envio.
| Saídas e Pós-Condições: O sistema deverá registrar o atestado enviado, disponibilizá-lo para análise da escola e informar ao aluno que o envio foi realizado com sucesso. A solicitação deverá ficar com o status “Aguardando análise”.



| RF002
| Conexão com a Internet
| O sistema deve estar conectado com a internet para seu funcionamento.
| Alta/Essencial

| RF003
| Anexo de arquivos
| A área de anexo de arquivos deve estar sempre funcional.
| Alta/Essencial

| RF004
| Conexão com banco de dados
| O sistema deve estar sempre conectado ao banco de dados para o envio dos arquivos.
| Alta/Essencial
|===

NOTE: Todos os requisitos listados nesta seção são **essenciais** para a operação inicial da aplicação e compõem o escopo prioritário de desenvolvimento.
